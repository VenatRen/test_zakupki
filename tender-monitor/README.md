# 223-FZ Education Tender Monitor

Мониторинг закупок по 223-ФЗ для образовательных услуг.

## Критерии отбора

Основной критерий:
- OKPD2 = 85.*

Дополнительный критерий:
- образовательные услуги / обучение / ДПО / повышение квалификации / переподготовка

## Источники

- ЕИС (заглушка)
- ФАБРИКАНТ (реализован)
- ТЭК-Торг (заглушка)
- РТС-Тендер (заглушка)

## Запуск

1. Скопировать `.env.example` в `.env`
2. Заполнить переменные окружения
3. Запустить:

```bash
docker compose build
docker compose up -d
```

## Проверка

```bash
curl http://localhost:8000/health
```

## Telegram уведомления

Создать бота через BotFather и указать токен в `.env`.

## Архитектура

```
Источники → Collectors → Raw data → Normalization → Deduplication → PostgreSQL → Telegram
```
